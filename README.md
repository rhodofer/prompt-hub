# Prompt Hub

> Save, manage, and instantly copy your reusable AI prompts directly inside VS Code.

## Features

- 📝 **Add** prompts with a title and full content
- 📋 **Copy** any prompt to clipboard with a single click
- ✏️ **Edit** existing prompts inline
- 🗑️ **Delete** prompts you no longer need
- 💾 **Persistent** — prompts survive VS Code restarts (stored via `globalState`)

## Usage

1. Click the **Prompt Hub** icon in the Activity Bar (left sidebar)
2. Press **+** to add a new prompt — enter a title, then the content
3. Click any prompt to copy it to clipboard
4. Right-click a prompt to **Edit** or **Delete** it

## Development

```bash
npm install
npm run compile   # single build
npm run watch     # watch mode (use with F5 debug)
```

Press `F5` in VS Code to launch the Extension Development Host.
